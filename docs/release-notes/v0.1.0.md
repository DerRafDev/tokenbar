The first public release of TokenBar: your AI usage limits, right in the macOS menu bar.

### What's included

- **Claude usage**: current session (5 h) and weekly limits, plus Opus/Sonnet weekly limits
  when your plan has them. Requires Claude Code signed in on your Mac.
- **Codex usage**: Codex 5-hour and weekly limits on your ChatGPT plan. Requires Codex
  signed in with ChatGPT on your Mac. These are Codex limits, not ChatGPT chat limits.
- **Menu bar display**: each provider's current session at a glance, or only the busiest
  one (Minimal), or session and week as `15/12` (Detailed).
- **Reset countdowns** in your time zone: "Resets at 19:10 (in 2h 50m)".
- **Automatic refresh** every 5 minutes (configurable), after wake, and when you open the
  popover. Old data is marked as outdated instead of disappearing.
- **Open at login**.
- **English and Portuguese (Brazil)**.
- **Private by design**: no server, no account, no analytics. TokenBar talks only to
  Anthropic and OpenAI, for the providers you enable. Usage data stays on your Mac.

### Experimental integrations

Claude and Codex do not offer a public API for plan limits. TokenBar uses the undocumented
endpoints that Claude Code and Codex themselves use, so either integration may break if
the providers change them. Both are disabled until you enable them, and TokenBar explains
what it reads before you do. Details: [docs/providers.md](https://github.com/DerRafDev/tokenbar/blob/main/docs/providers.md).

### Known limitations

- Codex installations that keep their sign-in in the Keychain (`keyring` mode) are not
  supported yet.
- Codex HTTP 403 is shown as "Sign-in expired"; TokenBar cannot yet tell it apart from
  Codex being unavailable for a workspace.

### Install

**This release is unsigned and not notarized by Apple**, so macOS Gatekeeper blocks the
first launch. That does not mean macOS found malware; the build has not gone through
Apple's Developer ID signing and notarization. Only open it if you downloaded it from
this page and trust the project.

Requires macOS 14 or later.

1. Download `TokenBar-0.1.0-unsigned.dmg`, open it, and drag TokenBar to Applications.
2. Open TokenBar. When macOS blocks it, open **System Settings › Privacy & Security**,
   find the message about TokenBar, and click **Open Anyway**, then confirm.
3. TokenBar opens normally from then on.

Do not turn off Gatekeeper for your whole Mac. Verify the download with
`shasum -a 256 -c SHA256SUMS.txt`. `TokenBar-0.1.0-unsigned.zip` contains the same app.

Developer ID signing and notarization are planned for a later release.
